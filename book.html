Connect Google Calendar (owner setup)

This page is ready to show live Mon–Sun 9–5 availability. Create a Google Calendar Appointment schedule, then paste the booking link into js/booking-config.js.

  1. Open Google Calendar → Appointment schedules (computer browser).
  2. Create schedule: Site visit / free quote — Straight Stud Construction.
  3. Duration: 60 minutes (or 30).
  4. Availability: Monday through Sunday, 9:00 AM – 5:00 PM, Eastern Time.
  5. Meeting type: in-person (job site) or phone.
  6. Save → Copy link (or Website embed → copy iframe URL).
  7. Paste into bookingPageUrl in js/booking-config.js and push the site.

Until the link is added, customers can still request a time by email: request@straightstudllc.com
